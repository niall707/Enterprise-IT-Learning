# Documentation Templates

Copy, rename and fill out the templates below. Remove instructional placeholders rather than leaving example output in published evidence.

| Template | Use for |
|---|---|
| [Course notes](course-notes-template.md) | Structured source-based learning and review |
| [Lab report](lab-report-template.md) | Reproducible technical exercises with validation |
| [Troubleshooting report](troubleshooting-template.md) | Hypothesis, diagnosis, remediation and prevention |
| [Runbook](runbook-template.md) | Repeatable operational response / maintenance procedure |
| [Case study](case-study-template.md) | Portfolio narrative backed by real, safe evidence |

**File convention:** `topic-or-exercise-name.md` in the relevant subject folder. Use `YYYY-MM-DD` dates inside the document.

**Privacy convention:** all identifiers should refer to lab or synthetic systems. Never copy employer records into these files.
