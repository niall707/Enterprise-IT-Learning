## Evidence workflow

1. Start a [course note](../templates/course-notes-template.md) for relevant training.
2. Perform the exercise on a personally controlled lab or with synthetic data.
3. Record a reproducible [lab report](../templates/lab-report-template.md) or [troubleshooting record](../templates/troubleshooting-template.md).
4. For a substantial result, write a [case study](../templates/case-study-template.md).
5. Link the completed material from the [progress tracker](../PROGRESS-TRACKER.md).
