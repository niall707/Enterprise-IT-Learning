# Systems Administration

**Purpose:** Linux and RHEL administration, filesystems, services, networking, security and operational troubleshooting.  
**Portfolio priority:** Primary — L2 readiness.

## Topics

| Topic | Scope |
|---|---|
| [RHEL](rhel/README.md) | RHCSA-aligned administration, package management, users/groups, SELinux and service operation |
| [Linux Fundamentals](linux-fundamentals/README.md) | shell navigation, processes, permissions, SSH and standard operating tools |
| [Storage and Filesystems](storage-and-filesystems/README.md) | partitions, LVM, mounts, capacity, filesystem health and recovery |
| [Networking](networking/README.md) | IP routing, name resolution, firewalls, ports and reachability checks |
| [Security](security/README.md) | least privilege, SSH hardening, SELinux, auditing and change control |
| [Troubleshooting](troubleshooting/README.md) | hypothesis-driven diagnostics, log review and incident evidence |
